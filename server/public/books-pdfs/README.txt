Put your downloaded book PDF files directly in this folder.

Example: if you put a file here named "pride-and-prejudice.pdf",
its PDF / Read URL for that book in your Admin panel will be:

http://localhost:5000/books-pdfs/pride-and-prejudice.pdf

Tips:
- Use simple file names: lowercase letters, numbers, and hyphens only
  (no spaces, no special characters) — e.g. "1984.pdf" or "clean-code.pdf"
- Keep files reasonably sized (under ~20 MB each) so pages load quickly
